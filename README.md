# Club Member Directory

This is a simple C program for managing club members.

## Features

- Add a member
- List all members
- Search members by domain
- Remove a member
- Exit the program

## Information Stored

For each member, the program stores:

- Member ID
- Member Name
- Domain

## How to Run

1. Open the `club_member.c` file.
2. Compile the program using a C compiler.
3. Run the program.
4. Select an option from the menu.

## Menu

1. Add Member
2. List Members
3. Search by Domain
4. Remove Member
5. Exit
